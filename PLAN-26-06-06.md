### Module 2: Startup weight reduction

Objective:
- Reduce critical bootstrap cost without destabilizing the app shell.

Implementation steps:
- Remove the static bootstrap import for `processedAssets.json`.
- Load large content payloads only after bootstrap with a dynamic import.
- Lazy-load heavy route and panel components with `React.lazy` and `Suspense`.
- Split vendor bundles more deliberately with `manualChunks`.
- Keep stricter build warning limits so regressions show up early.

Verification gate:
- Contract tests confirm dynamic import and lazy loading are present.
- Production builds complete without warnings.
- Offline Playwright coverage still passes after the split.

Outcome:
- Completed. Evidence is in `src/App.tsx`, `vite.config.ts`, and Module 4 verification records.
